# 👋 ¡Bienvenido a Gangain!

Somos una organización dedicada al desarrollo de soluciones tecnológicas innovadoras.

## 🚀 Nuestra Stack Tecnológica

### Frontend
- **React** - Biblioteca de JavaScript para construir interfaces de usuario
- **Next.js** - Framework de React para aplicaciones web
- **TypeScript** - JavaScript con tipado estático
- **Tailwind CSS** - Framework de CSS utilitario
- **Redux** - Gestión de estado de aplicaciones

### Backend
- **Node.js** - Entorno de ejecución de JavaScript
- **Express** - Framework web para Node.js
- **NestJS** - Framework progresivo de Node.js
- **PostgreSQL** - Base de datos relacional
- **MongoDB** - Base de datos NoSQL
- **Docker** - Plataforma de contenedores
